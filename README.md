# PressingPro - Gestion de Pressing Local

Application de gestion de pressing rapide, moderne et sécurisée avec stockage local.

##  Fonctionnalités
- ** Gestion CRUD** : Ajouter, modifier et supprimer des dépôts.
- ** Recherche & Filtres** : Recherche par nom/téléphone et filtres (À laver, Impayés).
- ** Suivi Financier** : Calcul automatique du chiffre d'affaires du jour.
- ** Alertes de Retard** : Notification visuelle pour les habits non récupérés(si possible).
- ** Mode Sombre** : Interface optimisée pour le confort visuel.
- **Offline First** : Les données sont sauvegardées localement dans le navigateur (IndexedDB).

##  Stack Technique
- **Frontend** : React.js (JSX) + Tailwind CSS
- **Base de données** : IndexedDB via Dexie.js
- **Icônes** : Lucide-React

##  Installation
1. `npm install`
2. `npm run dev`
